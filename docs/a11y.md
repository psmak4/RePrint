# Accessibility

RePrint targets WCAG 2.2 AA (PRD §11). Two layers check it:

- **Automated:** every Playwright spec calls `expectNoA11yViolations(page)` (`e2e/support/a11y.ts`), which fails on any serious or critical axe issue. `pnpm test:e2e` runs it in Chromium, WebKit, and a mobile viewport. Page types and where they are checked:

| Page type | Spec |
| --- | --- |
| Discover, Genres index, Genre, Series | `smoke`, `discover` |
| Search (Books and Authors) | `search` |
| Book (reviews, review form, delete confirmation) | `reviews`, `moderation`, `a11y-pages` |
| Author | `a11y-pages` |
| Profile, library | `library` |
| Register, log in, verify, forgot and reset password | `auth`, `password-reset` |
| Settings (profile, security) | `a11y-pages` |
| Legal and static pages | `a11y-pages` |
| Every admin page, user detail, Book edit | `admin`, `moderation`, `reports`, `a11y-pages` |

- **Manual:** axe finds about a third of real problems. The owner runs the script below before launch (M8-T15) and records results in the table at the end.

## Manual screen-reader script

Run each flow with the keyboard and a screen reader, with the monitor off if you can. Use **VoiceOver + Safari** on macOS (turn on with Cmd+F5) and **NVDA + Firefox** on Windows. Use `pnpm dev` with `pnpm db:reset` data, or staging.

For every page, check:

1. The page title is announced and describes the page.
2. The first Tab stops on "Skip to main content", and Enter moves focus to the main content.
3. Landmarks exist (banner, navigation, main, contentinfo); the rotor (VoiceOver: VO+U) or element list (NVDA: Insert+F7) shows a sensible heading outline with one level 1.
4. Focus is always visible and the Tab order follows the visual order.
5. Nothing is announced as "button" or "link" without a name; images have text alternatives or are skipped.

### Flows

| # | Flow | Steps | Expect |
| --- | --- | --- | --- |
| 1 | Search | Tab to the search box, type `dune`, wait, press Down and Up, press Enter | Suggestions are announced as a list with the count; the highlighted option is read; Enter opens the results page |
| 2 | Results | Reach the Books and Authors tabs, filters, and a result | Tabs say which is selected; filters have labels; each result reads title, authors, and rating |
| 3 | Book page | Open a Book | Cover has alt text; the rating summary reads the average, the count, and the distribution as text; "Read more" says whether it is expanded |
| 4 | Write a review | Sign in as a verified Member, open "Write a review" | The star input reads "N stars" and moves with arrow keys; character counters and errors are announced; submit reports the "Pending approval" status |
| 5 | Spoilers | Find a review with spoilers | The "Show spoilers" button says it is collapsed, then expanded |
| 6 | Helpful and report | Mark a review helpful; report a review | The button state change and the confirmation are announced |
| 7 | Shelves | Change a Shelf from a result, the Book page, and the library | The select has the Book's name in its label; the change is confirmed |
| 8 | Notifications | Open the bell with a notification | The unread count is part of the button name; the list is reachable; items read as read afterward |
| 9 | Auth | Register with a short password; log in with a wrong password | Field errors are tied to their fields and announced; focus moves to the first error |
| 10 | Settings | Change the display name; end a session; start the delete-account flow | Status messages are announced; destructive actions ask for confirmation |
| 11 | Moderation (Moderator) | Open `/admin/reviews`, use `J`/`K`/`A`/`R`, reject with a reason | Shortcuts are announced somewhere reachable; the decision result is announced; shortcuts do not fire while typing |
| 12 | Admin tables | Open `/admin/users` and `/admin/audit` | Tables have headers and captions; the scrollable region is keyboard reachable; pagination says the current page |

### Also check

- Zoom to 200% and 400% (320 px wide): no horizontal scrolling of the page, nothing cut off.
- Windows High Contrast / macOS Increase Contrast: borders and focus rings remain visible.
- `prefers-reduced-motion`: no animation beyond fades.
- Text spacing bookmarklet (WCAG 1.4.12): nothing is clipped or overlaps.
